Журнал
Сброс

Все настройки, в том числе режим, маршрутизация, DNS, списки сайтов и приложения в VPN, вернутся к значениям по умолчанию и сразу сохранятся. Серверы, подписки, выбранный сервер, отметки автовыбора и отпечатки отдельных серверов останутся; пароль для устройств в сети и идентификатор устройства не меняются.

Туннель

Для VLESS, в том числе Vision. Выключено — своё соединение на каждый адрес. В XHTTP не действует: там UDP и так идёт общим пулом.

Локальный прокси

Устройствам в сети нужен этот логин и пароль; программы на этом компьютере подключаются без пароля.

DNS

Адрес 1.1.1.1 — обычный DNS (порт 53); свой порт — 1.1.1.1:5353 или udp://1.1.1.1:5353, IPv6 — [::1]:5353; tcp://1.1.1.1:53 — только по TCP; https://сервер/dns-query — DNS через HTTPS (https://сервер:8443/путь), tls://сервер — DNS через TLS (tls://сервер:853, сертификат проверяется). Без домашнего DNS удалённый отвечает за все сайты: запросы идут по тем же правилам, что и трафик (при «Всё через VPN» — через сервер), а адреса сайтов «напрямую» узнаются у него напрямую. С домашним DNS сайты, которые по правилам идут напрямую, спрашиваются у домашнего напрямую, а все остальные — у удалённого и только через VPN; имена сайтов через VPN домашний DNS не видит. Имя DoH/DoT-сервера узнаётся у серверов из списка, заданных IP-адресом, а без них — у Cloudflare и Google через HTTPS.

Для сайтов через VPN.

Для сайтов напрямую. Пусто — удалённый DNS, напрямую.

Списки сайтов

По одному на строку: домен (с поддоменами), full:точный.домен, keyword:слово, IP или подсеть, geosite:категория, geoip:код.

Остальным доменам Unbihex не даёт вести в локальную сеть (защита от DNS rebinding).

Блокировка рекламы

Домены из списков (формат hosts) не открываются, а в режиме TUN и на Android их имена не находятся. Сайты из «Всегда через VPN» и «Всегда напрямую» не блокируются. Списки скачиваются у авторов после сохранения и обновляются раз в неделю.

Автовыбор сервера

Группа — выбранный сервер и остальные серверы его подписки, которые поддерживает ядро (до 20), или только отмеченные серверы из любых подписок. Исключить сервер или отметить его — кнопка со стрелками в строке сервера (видна, когда автовыбор включён); выбранный сервер входит в группу всегда. Каждый проверяется запросом к www.gstatic.com раз в минуту и сразу после сбоя; при сбое новые соединения идут через следующий сервер, открытые не рвутся. Текущий сервер виден под кнопкой подключения.

Приложения в VPN

«Только выбранные» — через VPN идут только отмеченные приложения, «все, кроме» — все, кроме отмеченных. Unbihex сам всегда работает мимо VPN. Если ни одного отмеченного приложения нет на телефоне, через VPN идут все. Действует со следующего подключения.

Отпечаток TLS

Какой браузер изображает TLS-рукопожатие (VLESS, VMess, Trojan, TrustTunnel, NaiveProxy). «Как в ссылке» — параметр fp сервера. Для одного сервера отпечаток можно задать кнопкой в его строке. С REALITY отпечатки без ML-KEM — iOS, Android, Edge, 360 и QQ — сервер Xray 26 не пустит (он требует X25519MLKEM768).

Обход DPI

ClientHello уходит мелкими частями (VLESS с TLS или REALITY).

Подписки

Провайдеру уходят имя, система и случайный идентификатор (x-hwid); по ним панели с лимитом устройств различают устройства.

Пусто — имя компьютера или модель телефона. Уходит только с запросом подписки.

При активном подключении оно перезапустится.
